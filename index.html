How I Work

01

Spec before code

I write the spec first: data model, states, failure paths. It costs a day and saves a rewrite. Architecture follows from it: MVVM, VIPER on the banking app, whatever the problem actually needs.

02

AI as a multiplier

Claude Code and Cursor sit in my daily loop, with custom agentic skills for the repetitive parts. I ship LLM features too: multi-provider routing with fallback across Claude, Gemini and GPT-4o.

03

Ship, then own it

XCTest and XCUITest on the critical paths, Instruments when the frame budget slips, crash triage after release. On the banking app that discipline took the crash rate to near zero across 30+ sprints.
